# 知行手记 · 个人学习档案

网站：https://imxiel126.github.io/library/

面向计量检测、氢能工程、电催化、碳排放、水生态环境、科研转化、机器学习、认知思辨和阅读的结构化学习中心。保留原有新闻联播晨读、归档和邮件任务。

## 数据清单（2026-11-23）
| 文件 | 数量 | 说明 |
|---|---:|---|
| data/books.json | 1,000 | 独立真实书目，其中 90 部已经整理原创内容概述，其余仅有原始书目信息与通用阅读提示，明确标记待精读 |
| data/quotes.json | 1,000 | 60 条通行典籍格言 + 940 条唐诗摘录；各条带作者、作品与来源路径。正式引用应核对原典。 |
| data/insights.json | 1,000 | 100 个技术与跨领域学习主题，每个主题十个研习角度：定义、问题、场景、误区、数据、反证、迁移、表达、应用、复盘。**不应称为 1,000 个独立知识主题**。 |

书目基础数据来自 [1001-books](https://github.com/temporal-communities/1001-books) 整理数据；唐诗摘录参考 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 公开数据。**未将未核读的图书伪装成已有详细摘要；也未把原创学习卡片伪装成名人原话。** 这些栏目为学习辅助资料，不替代学术引用、标准文件或现场测量判断。

## 页面功能
- 3,000 条跨栏目即时搜索（支持中文词和英文标题）
- 分类、主题过滤、20 条分页
- 每天按照北京时间（Asia/Shanghai）轮换一部书、一条名言、一张知识卡；点击“换一组灵感”临时更换
- 查看来源、详情和本地收藏（收藏只保存在当前浏览器的 localStorage 中，不跨设备同步）
- 适配手机和桌面；不要求后端、数据库、登录或额外 API token

## 发布
根目录 `index.html` 是自动生成的新闻晨读页。**不要只改该文件的导航而忘记更新 `scripts/first-issue.html`**，因为每日任务会从它重新生成首页。

`.github/workflows/daily.yml` 使用 GitHub Pages artifact 发布 `index.html`、`archive/`、`reading/`、`notes/`、`library/`。仓库已分别建立独立目录以便持续演进，不能让一个页面的内容覆盖另一个栏目。
