# 知行手记 · 个人学习台

公开入口：<https://imxiel126.github.io/learn/>

这是一个在 GitHub Pages 上运行的 **纯前端、浏览器本地** 学习工具。目标不是展示“我收集了多少内容”，而是把每天读到的新闻、研究资讯、书籍和专业知识变成可回顾的个人经验。

## 一次 10 分钟的使用流程

1. **2 分钟，晨读**：打开首页，浏览聚焦的前五条央视报道和研究新讯。看到有价值的原文，点击“＋ 稍后读”，不要用复制粘贴转存。
2. **4 分钟，今日三学**：打开学习台，读一部已有可信原创摘要的书、一句典籍格言、一个研究知识点，点击“标记已学”。
3. **2 分钟，形成判断**：在“今日想法”写一个问题，再用三句话记录新发现、改变了什么认识、下一步做什么。
4. **2 分钟，间隔复习**：复习到期卡片，或者将知识库中有价值的书、名言、知识卡加入复习计划。

## 页面功能

- 日期使用 `Asia/Shanghai`，当日三张学习卡每日轮换，也可以手动换一组。
- 从首页新闻、研究资讯一键存到“稍后阅读”。从知识库详情可一键加入复习计划。
- 默认复习间隔为 1、3、7、14、30、60 天，由用户确认“已回忆”后安排下一次复习。
- 记录每日问题、笔记、最近七天学习情况和连续学习天数。
- 在学习台输入搜索词或按 `/` 聚焦搜索框，直接检索 3000 条书籍、名言和知识条目。
- 提供 JSON 导出与导入，支持自己备份或转移浏览器。

## 隐私与限制

学习台将以下个人数据写入**当前浏览器的 localStorage**：

- `zhixing-days-v1`：学习打卡、问题与日记；
- `zhixing-review-v1`：知识卡间隔复习安排；
- `zhixing-queue-v1`：稍后阅读链接；
- `learning-favorites`：原知识库中已收藏的条目。

**不会自动上传到 GitHub、邮箱或服务器，不会跨设备同步，也不需要任何 API 密钥。** 浏览器数据清理、换设备或使用无痕模式可能导致记录丢失，建议定期使用导出功能保存文件。导入备份前会确认覆盖。

## 维护说明

- `learn/index.html`：页面结构；
- `learn/learn.css`：样式；
- `learn/app.js`：浏览器本地逻辑，不调用外部服务；
- `scripts/check_site_integrity.py`：结构完整性、数据量与前端脚本检查；
- `scripts/check_daily_updates.py`：网站与数据更新时间监控。

每条动态信息应分清**节目播出时间、资讯发布日期、数据源内容更新时间、自动同步运行时间**。来源没有新内容时，页面应显示真实最后更新时间，不应为了表现“每日更新”而伪造新的新闻或研究结果。
