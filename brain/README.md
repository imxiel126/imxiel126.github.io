# 知行手记 · 第二大脑

**入口：<https://imxiel126.github.io/brain/>**

这是一座为自己而建、可以长期运行的个人信息系统，不是把所有文章照单全收的资料仓库。目标是将“看到的内容”通过主动加工转化为“能检索、能回忆、能行动、能验证”的知识与成果。

## 工作流：收集 → 提炼 → 连接 → 调度 → 复盘

| 阶段 | 入口 | 最小可执行动作 | 认知目的 |
|---|---|---|---|
| 收集 | 收集箱 | 一句话 + 原始出处，先存后分 | 降低输入阻力和切换成本 |
| 提炼 | 知识笔记 | 自己的解释、证据、应用，以及可自测的问题 | 避免单纯摘抄的理解错觉 |
| 连接 | 主题标签与关联项目 | 笔记联系真实项目或一个新的问题 | 提高未来检索与迁移概率 |
| 调度 | 全域搜索、行动与复习 | 搜索需要的内容，形成一条明确行动 | 让知识随用随取 |
| 复盘 | 每周回顾 | 记一条认识、一个阻碍、一个下周动作 | 减少未整理信息的积累 |

**不要以收集多少条作为成功标准。** 更值得衡量的是：多少条信息被解释、多少个问题有新证据、多少项行动被完成、多少知识在需要时能成功回忆。

## 适合日常使用的节奏

**晨间 5–10 分钟：** 打开[晨读](/)，只看几条与当天工作相关的信息，发现值得深入研究的文章就点击“收入第二大脑”，不必一次全部看完。

**工作间隙 30 秒：** 进入第二大脑收集箱，记录突然出现的技术问题、研究线索或待办。若正在集中工作，只保留一句话，稍后再加工。

**每天 10 分钟：** 从[学习台](/learn/)查看一书、一言、一思，做几条到期主动回忆；再从收集箱挑 **1 条** 加工成带来源和应用情景的永久笔记。

**每周 15 分钟：** 清理收集箱与积压任务，把重要知识关联到真实项目，复盘本周最有价值的认识、最重要的阻碍与下周第一步。

### 可使用的主题

计量与检测、氢能与能源、生态环境、科研与转化、AI 与编程、阅读与写作、工作与项目、生活与成长；你可以直接搜索具体名词，不必完全按主题存储。

例如，读到“液体流量计在线校准”材料，可以存入收集箱，转换成“影响在线校准结果的关键工况是什么？”笔记，附上检定规范/试验报告来源，并将它关联到“方法验证”项目。下一步行动可以写成：“当明天打开工作电脑后，我就整理前次实验中不同流量点的示值数据”。这些是**操作示例，不会自动当作你已开展的实际项目存入系统**。

## 一次搜遍哪些内容？

- **私人内容：** 第二大脑的收集箱、知识笔记、项目、行动、周复盘，以及学习台现有本地学习日记和稍后阅读。
- **公开内容：** 1,000 部书目、1,000 条名言诗句、1,000 张跨学科卡片、2,000 张阅读思考卡、微信读书已公开的书架资料、公开研究论文和科研资讯、公开精选笔记。
- 搜索会优先匹配题名、主题、关键词和私人笔记。**这是本地全文关键字检索，不是语义向量检索，也不会自动推理未经证实的知识关系。** 资料来源可能偶尔不同步，UI 会标注。

## 隐私、安全和数据持久性

所有私人笔记、问题、收集、项目、行动、复盘均写入 `localStorage`，不会自动推送到公开 GitHub 仓库。GitHub Pages 只托管前端代码与经筛选的公开数据。

**重要限制：**

1. 个人资料仅保留在当前浏览器；换手机、换电脑、浏览器隐私模式或清理缓存后，不能依靠 GitHub 页面自动找回。
2. **导出的 JSON 文件不加密。** 里面含个人笔记和学习记录，请存放在自己管理的加密硬盘或可信私有空间；不要上传至公共仓库。
3. 备份可以在第二大脑中导入；导入会在明确确认后覆盖当前设备的记录。建议导入前先导出旧数据。
4. GitHub Actions 定时更新的只是公开资讯与页面内容；不会为本地私人笔记自动进行 GitHub 私有同步。
5. 公开研究/新闻资料适合作为检索入口，涉及实验、计量规范和专业决策时，必须核对原始证据和现行标准。

## 设计所依据的证据

- John Dunlosky 等，《[Improving Students’ Learning With Effective Learning Techniques](https://doi.org/10.1177/1529100612453266)》（2013）：对多种学习策略的综述，评价实践测验/提取练习与分散学习具有较广泛的实用价值。
- [Nature Reviews Psychology](https://doi.org/10.1038/s44159-022-00089-1)，*The science of effective learning with spacing and retrieval practice*（2022）：综述间隔与提取对学习保持的作用。
- Peter Gollwitzer 与 Paschal Sheeran，《[Implementation Intentions and Goal Achievement](https://doi.org/10.1016/S0065-2601(06)38002-1)》（2006）：关于明确“何时、何地、做什么”的实施意图的元分析。

具体的复习间隔和界面流程是为了降低使用成本所选的默认规则，并不意味着每个人都适用同样的时间表。

## 技术结构

| 文件 | 用途 |
|---|---|
| `brain/index.html` | 收集箱、笔记、项目、搜索、周复盘 |
| `brain/app.js` | 前端逻辑与本地备份 |
| `brain/brain.css` | 桌面与手机排版 |
| `assets/brain-bridge.js` | 由晨读、知识库、研究页及阅读页一键收集 |
| `learn/` | 每日学习与间隔复习 |
| `scripts/check_site_integrity.py` | 自动检查页面、脚本、导航与自动发布流程 |

未来若需要真正的跨设备私有同步，应另行设计**私有加密数据存储及访问控制**，绝不可把 GitHub Personal Access Token 写入网页代码或公开仓库。
