连接你真正看到的知乎、小红书推荐

这里的「推荐」特指你登录后进入平台推荐页时看到的个性化内容，不是关键词搜索、热榜或同主题文章。

当前状态：等待你本人授权浏览器同步。

仅有公开主页地址不能取得你的个性化推荐流。浏览器同步扩展目前已写入 GitHub 仓库，但尚未安装或连接，不会自动采集推荐。

一次性开启浏览器端同步

  1. 在 GitHub 仓库中点击 Code → Download ZIP，解压下载文件。
  2. 在 Chrome 或 Edge 地址栏打开 chrome://extensions/ 或 edge://extensions/，启用开发者模式，点击“加载已解压的扩展程序”，选择解压目录内的 tools/personal-feed-extension 文件夹。
  3. 在 GitHub Fine-grained Token 设置中建立仅针对 imxiel126/imxiel126.github.io 的 token，仅授权 Contents: Read and write，不要创建全账号 token。
  4. 点击浏览器扩展，在设置里填写仓库名及 token，确认个人推荐卡片将被公开展示后启用同步。
  5. 登录并访问 知乎推荐或 小红书推荐。扩展将尝试抓取页面可见卡片并提交仓库；随后首页展示同步结果。
重要隐私提醒

你看到的推荐可能暴露个人兴趣与阅读偏好。同步后的卡片标题、链接及短摘要会进入公开仓库，且 Git 历史可能保留。程序不读取 Cookie、密码或私信。只有浏览器打开并实际浏览推荐页时才会更新，不能承诺全天实时同步；平台页面升级也可能使采集失效。

程序源代码和技术说明均可在 GitHub 查看。建议先检查代码、确认公开范围后再启用。
